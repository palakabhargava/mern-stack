# MERN-STACK

A simple MERN backend application developed for learning CRUD operations using Node.js, Express.js, and MongoDB.

## Features

- Create Goals
- Read Goals
- Update Goals
- Delete Goals
- MongoDB Database Integration
- Express REST APIs

## Tech Stack

- MongoDB
- Express.js
- Node.js

## Project Structure

backend

 ├── config

 ├── controllers

 ├── middleware

 ├── model

 ├── routes

 └── server.js

## API Endpoints

GET /api/goals

POST /api/goals

PUT /api/goals/:id

DELETE /api/goals/:id

## Installation

```bash
npm install
npm run server
```
